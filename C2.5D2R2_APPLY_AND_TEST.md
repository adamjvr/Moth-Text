# Apply, test, commit, and prove Moth C2.5D2R2

Luna must be completed first.

## 1. Verify Moth and capture the committed Luna repair

```bash
cd ~/GitHub/Moth-Text

git switch a1.1-measured-audit
git pull --ff-only

git rev-parse HEAD
git status --short
```

Expected Moth HEAD:

```text
f4941d6b7c6b2bdac5bb0b826076eaee315e75a6
```

Capture the exact committed Luna C2.5D2R2 SHA:

```bash
LUNA_C25D2R2_SHA="$(
  git -C ~/GitHub/Luna-UI rev-parse HEAD
)"

git -C ~/GitHub/Luna-UI \
  show --no-patch --oneline \
  "$LUNA_C25D2R2_SHA"
```

## 2. Advance Moth's real Luna submodule

```bash
git -C Dependencies/Luna-UI fetch \
  origin \
  a1.1-measured-audit

git -C Dependencies/Luna-UI checkout \
  "$LUNA_C25D2R2_SHA"

test \
  "$(git -C Dependencies/Luna-UI rev-parse HEAD)" = \
  "$LUNA_C25D2R2_SHA"

git -C Dependencies/Luna-UI status --short
git diff --submodule=short -- Dependencies/Luna-UI
```

The nested Luna status must be clean. The outer Moth repository should show
only the changed `Dependencies/Luna-UI` gitlink before extraction.

## 3. Extract the Moth repository overlay

```bash
unzip -o \
  ~/Downloads/Moth-Text-C2.5D2R2-Repository-Overlay.zip \
  -d .
```

This ZIP deliberately excludes `Dependencies/Luna-UI/**`.

## 4. Apply the guarded Moth source repair

```bash
./scripts/apply-c2.5d2r2.sh

git diff -- \
  Sources/MothApplication/MothApplicationShellScene.swift

./scripts/verify-c2.5d2r2-working-tree.sh
```

## 5. Focused validation

```bash
swift package reset
swift package resolve

swift test \
  --filter MothC25D2PartialDamageTests

swift test \
  --filter MothC25DFramePathDiagnosticsTests
```

When the second exact test class is not present in the current checkout,
`swift test` will report no matching tests; continue with the complete suite,
which remains authoritative.

## 6. Full paired validation

```bash

./scripts/test-paired.sh

```

```text

```
