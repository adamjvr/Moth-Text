Moth Text M1.1 repository overlay

1. Extract this ZIP directly over your existing Moth-Text Git repository.
2. From the repository root, update the existing Luna-UI submodule normally:

   ./scripts/update-luna.sh

3. Build, test, and run:

   swift package clean
   swift build
   swift test
   swift run MothTextLinux

4. Run the plugin smoke test:

   ./scripts/smoke-test-plugin-host.sh

The ZIP does not contain Dependencies/Luna-UI and does not replace your .git directory.
The update-luna.sh script switches the Luna submodule to main and pulls with --ff-only.
