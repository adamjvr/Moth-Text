# Apply and validate Moth C2.5B

Advance `Dependencies/Luna-UI` to the exact committed Luna C2.5B SHA first, then:

```bash
cd ~/GitHub/Moth-Text
unzip -o ~/Downloads/Moth-Text-C2.5B-Repository-Overlay.zip -d .
git diff --check
swift package reset
swift package resolve
swift test --filter MothC25BWrapIndexStoreTests
swift build
swift test
./scripts/test-paired.sh
./scripts/validate-iteration.sh
./scripts/smoke-test-plugin-host.sh
```

Commit Moth files and the Luna gitlink together:

```bash
git add Sources/MothApplication/MothDocumentWrapIndexStore.swift \
        Tests/MothApplicationTests/MothC25BWrapIndexStoreTests.swift \
        docs/C2.5B_WIDTH_KEYED_WRAP_STORE.md \
        C2.5B_APPLY_AND_TEST.md \
        Dependencies/Luna-UI
git diff --cached --check
git diff --cached --submodule=short
git commit -m "feat(editor): cache C2.5B wrap indices by revision and width"
git push origin a1.1-measured-audit
```
