# C2.5D2 — Bounded Moth editor damage

Moth now uses Luna's rectangular framebuffer restore for two safe classes of
application updates.

## Document edits

A normal text-input frame restores and redraws:

- the document title and dirty-state bar;
- the complete split-pane editor area;
- the minimap;
- the status bar.

The sidebar, menu bar, and unrelated window background are preserved.

Both editor panes are redrawn because they share the same Moth-owned document
buffer and may expose different viewports into the changed text.

## Pane-only visual updates

Scrolling, selection changes, and caret blinking restore and redraw:

- the split-pane editor area;
- the status bar.

## Conservative fallback

The complete scene remains mandatory for:

- initial presentation;
- resize;
- generic pointer or keyboard input;
- commands;
- menus and command palette;
- workspace and theme changes;
- any unclassified or mixed invalidation.

The cache is refreshed after every complete frame and after every bounded update,
so repeated text input never restores an older document revision.
