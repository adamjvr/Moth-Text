# C2.5D2R2 — verified Moth runtime integration

Moth already contains the C2.5D2 geometry, damage-plan, and backing-cache
primitives. The application shell itself still performs a full framebuffer
clear and complete redraw for every frame.

C2.5D2R2 connects those primitives to the live shell.

## Partial document-edit frame

For ordinary text/document invalidation with a compatible cache:

- restore the document bar;
- restore both pane surfaces;
- restore the minimap;
- restore the status bar;
- redraw the current document title;
- redraw panes, caret, selection, text, minimap, and status;
- copy the newly rendered regions back into the backing cache;
- report `.partialDamage`.

## Partial pane-visual frame

For scrolling, selection-only changes, or caret blink:

- restore pane and status regions;
- redraw panes and status;
- update those same backing-cache regions;
- report `.partialDamage`.

## Full-scene cases

Complete rendering remains mandatory when:

- no compatible cache exists;
- the menu or command palette is open;
- resize invalidates framebuffer geometry;
- a document is installed or replaced;
- invalidation reasons do not map safely to a bounded damage kind.

## Delivery integrity

The overlay validates the working source, staged index, committed shell blob,
and committed Luna gitlink separately. A documentation-only commit cannot pass
the committed verification script.
