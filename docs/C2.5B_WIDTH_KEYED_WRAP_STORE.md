# C2.5B — Width-Keyed Wrap Index Store

Moth now owns cache lifetime for Luna wrap indices. Equal document revision,
logical line, and viewport width reuse one immutable index across panes.

The key intentionally excludes pane-local state:

- scrolling;
- selection;
- caret;
- focus.

An edit produces a new presentation revision and therefore a distinct cache key.
Moth may invalidate one revision, every revision of a document, or the complete
store.
