# C2.5D2R2 v2 patch-application repair

The first C2.5D2R2 ZIP contained the intended source edits, but its generated
unified diff serialized blank context lines without the required leading
context marker. `git apply` therefore rejected the first Luna hunk even though
the checked-out source blob was exactly the required baseline.

Version 2 preserves the source edits and adds
`scripts/apply-exact-unified-diff.py`. The guarded shell scripts first verify the
exact branch, commit, and source blob SHA. The helper then locates every complete
old hunk body exactly and performs all replacements atomically.

The same repair is included for Moth because its patch was generated by the same
process.

Obsolete C2.5D3 files must be removed before any Swift test. SwiftPM compiles all
source files in a selected test target even when `--filter` names another test.
