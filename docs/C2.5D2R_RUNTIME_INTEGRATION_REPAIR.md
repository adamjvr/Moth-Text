# C2.5D2R — Moth bounded-damage runtime integration repair

C2.5D2 committed the Moth damage planner and backing-cache type, but the
application shell still cleared and redrew the complete framebuffer.

C2.5D2R wires the planner into `MothApplicationShellScene`.

## Document-edit path

For a compatible cache and a normal text-input invalidation, Moth restores and
redraws:

- the document title and dirty-state bar;
- the split-pane editor area;
- the minimap;
- the status bar.

The menu bar, sidebar, and unrelated background remain untouched.

## Pane-visual path

Scrolling, selection changes, and caret-blink invalidations restore and redraw:

- the split-pane editor area;
- the status bar.

## Cache lifecycle

A full render creates or replaces the complete backing cache. Every successful
bounded render updates the same regions in the cache, preventing the next input
frame from restoring an older document revision.

Resize and document installation discard the cache. Menus, command palette,
generic input, commands, and unclassified mixed invalidations remain on the
complete path.

## Chrome split

Application-title, document-title, and status rendering are separate helpers.
A bounded text update therefore does not redraw the unchanged top application
title outside its damaged region.
