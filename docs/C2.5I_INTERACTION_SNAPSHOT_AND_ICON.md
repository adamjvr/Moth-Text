# C2.5I — Interaction Snapshot Reuse and Linux App Identity

C2.5H removed eager per-line `String` creation and changed the minimap to use
metadata-only line lookups. Native testing still found the 50,000-line fixture
sluggish even though one presentation was built and subsequent requests hit the
revision cache.

C2.5I attacks the next measured layer:

- one shared Luna presentation bundle for panes and minimap during a frame;
- one event-scoped pane geometry/surface snapshot for pointer and scrollbar work;
- timing counters for presentation lookups and interaction-snapshot construction;
- a complete current-user Linux application installation path;
- the approved Moth icon, preserving the original artwork and gradient while
  making only the exterior white background transparent.

The interaction snapshot is deliberately short-lived. It is built from the current
document revision, pane geometry, viewports, and active pane, used for one host
interaction, then discarded. This avoids stale state while eliminating repeated
surface construction inside the same pointer event.

## Acceptance

C2.5I is accepted only when:

1. the complete Swift test suite passes;
2. the 5,000-line native fixture remains smooth;
3. the 50,000-line fixture is stable and usable;
4. the trace analyzer confirms presentation request count is bounded relative to
   rendered frames and interaction snapshots;
5. the installed desktop entry displays the Moth icon.

If the native 50,000-line result fails, the script does not commit Moth.
