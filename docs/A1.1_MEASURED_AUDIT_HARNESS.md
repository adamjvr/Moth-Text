# A1.1 — Moth Measured Audit Harness

This paired slice consumes Luna's observational A1.1 API and adds deterministic
Moth-owned fixtures plus JSON/CSV reporting. It does not implement virtualization,
real document tabs, or visible Find/Replace.

## Focused tests

```bash
swift test --filter MothA1AuditTests
```

The normal focused run executes the fixture generator and a bounded 50-line probe.
The expensive matrix is skipped unless explicitly enabled.

## Full measurement matrix

```bash
MOTH_RUN_A1_FULL_AUDIT=1 \
MOTH_A1_OUTPUT_DIR=.build/a1.1-audit \
swift test --filter MothA1AuditTests/testFullAuditMatrixWhenExplicitlyEnabled
```

Outputs:

```text
.build/a1.1-audit/A1.1_RESULTS.csv
.build/a1.1-audit/<fixture>-<line-count>-<wrap>.json
```

The matrix includes 50, 500, 5,000, and 50,000 logical lines for ASCII, Unicode,
tabs, wrapped paragraphs, and long logical lines with wrapping enabled and disabled.

## Interpretation

The current Moth shell owns two panes, so the first integrated harness measures both
pane surfaces. One-pane and equal/unequal-width policy experiments remain part of the
subsequent audit execution/reconvene, not a hidden production behavior change.

A1.1 establishes measurement capability. It does not claim scalability acceptance.
