# C2.5A — Shared Revision Presentation Store

## Purpose

Moth now has an explicit product-owned store for sharing one immutable Luna source
presentation across editor panes and auxiliary consumers.

## Ownership boundary

Moth owns:

- document identity;
- document revision;
- cache lifetime and invalidation;
- pane-local viewport, scroll, selection, caret, and focus;
- minimap policy.

Luna owns:

- immutable logical text presentation;
- viewport planning;
- reusable product-neutral geometry and layout contracts.

## Reuse guarantees

For the same `(documentID, revision)` and source text, the store returns the same
`LunaStaticTextPresentationSnapshot` object. This allows tests and diagnostics to
prove that two panes and a minimap do not independently parse the same revision.

A new revision creates a new immutable snapshot. Older snapshots remain valid until
Moth invalidates them.

## Integration follow-up

The next Moth integration checkpoint wires the application document/session model,
both pane builders, and minimap construction through this store. Existing pane-local
interaction state must not move into the shared snapshot.
