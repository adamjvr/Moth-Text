# C2.5H — Large-Document Interactive Path

## Native finding

C2.5G substantially improved 50, 500, and 5,000-line fixtures. The 50,000-line
fixture remained functional but felt sluggish.

## Root cost addressed

The real editor was viewport-bounded after C2.5G, but each immutable Luna document
still eagerly allocated one line string per logical line. The minimap also
materialized sampled line strings merely to obtain their UTF-8 lengths.

## Paired change

Luna C2.5H provides a compact UTF-8 line index, lazy line materialization, and
metadata-only line access. Moth C2.5H consumes line metadata for minimap drawing
and records one metadata lookup per minimap sample.

This phase intentionally preserves:

- one immutable presentation per Moth revision;
- one shared virtualization context for both panes;
- bounded minimap sample count;
- partial-damage rendering after warm-up;
- exact Luna gitlink pinning.

## Acceptance

Automated tests must pass. Native 5,000-line behavior must not regress, and the
50,000-line fixture must remain stable while showing a clear responsiveness or
memory improvement over C2.5G. Record honest subjective results and generated
trace/time evidence before committing Moth.
