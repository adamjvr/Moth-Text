# C2.5D — Moth frame-path reporting

Moth now participates in Luna's frame-reporting contract.

The Linux scene forwards the host invalidation set into
`MothApplicationShellScene`, consumes the report immediately after rendering,
and returns it to `LunaHostSDL`.

Moth currently reports `.fullScene` because its application shell still draws
the complete framebuffer. This makes that cost visible in the same statistics
used by the Kitchen Sink and establishes the measurement boundary needed for
later pane- and caret-region invalidation.
