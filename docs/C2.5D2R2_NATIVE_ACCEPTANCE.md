# Moth C2.5D2R2 native acceptance

Run:

```bash
swift run MothTextLinux
```

Confirm:

- the initial frame reports `fullScene`;
- ordinary printable typing reports `partialDamage`;
- text appears in both views of the shared document immediately;
- caret and selection remain current;
- dirty state, revision/history status, minimap, and document title remain
  current;
- wheel and trackpad scrolling report `partialDamage`;
- no old text, caret, selection, minimap, or status pixels remain;
- opening the menu or command palette forces `fullScene`;
- closing overlays allows ordinary typing and scrolling to return to
  `partialDamage`;
- resize performs a complete rebuild;
- opening or installing another document invalidates the old backing cache;
- saving and editing again do not leave stale modified/saved status text.

Do not commit Moth until this manual application test passes.
