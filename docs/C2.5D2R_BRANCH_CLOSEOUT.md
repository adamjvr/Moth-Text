# C2.5D2R — paired branch closeout

Complete and push the repair in both repositories before merging either audit
branch.

## 1. Merge Luna first

```bash
cd ~/GitHub/Luna-UI
git switch a1.1-measured-audit
git pull --ff-only
./scripts/verify-c2.5d2r-integration.sh
swift test

LUNA_REPAIR_SHA="$(git rev-parse HEAD)"

git switch main
git pull --ff-only
git merge --ff-only a1.1-measured-audit
git push origin main

git merge-base --is-ancestor \
  "$LUNA_REPAIR_SHA" \
  origin/main
```
