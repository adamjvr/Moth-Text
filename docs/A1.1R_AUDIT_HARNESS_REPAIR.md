# A1.1R Moth Audit Harness Repair

The original Moth A1.1 overlay failed because Moth still pinned the pre-A1.1
Luna commit and because the persisted Moth result directly stored a Luna-owned
snapshot type.

A1.1R corrects both concerns:

- Moth must pin the exact locally committed Luna A1.1/A1.1R revision;
- `MothA1LunaMetrics` copies primitive public counters from Luna;
- Moth JSON/CSV output is product-owned and versioned;
- CSV construction uses explicit `[String]` values to avoid Swift type-checker
  complexity;
- JSON encode/decode and CSV column parity are regression-tested.

The normal focused suite is bounded. The 50/500/5,000/50,000-line matrix remains
explicitly gated by `MOTH_RUN_A1_FULL_AUDIT=1`.
