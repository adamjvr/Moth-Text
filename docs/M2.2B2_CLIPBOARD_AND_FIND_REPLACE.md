# M2.2B2 — Clipboard and Visible Find/Replace Convergence

## Status

Implementation delivery for the accepted M3A product line. This phase continues
on the existing `m3a-document-sheets-tabs` branch; it does not create another
phase branch.

## Product goal

M2.2B2 completes two editor fundamentals as one focus-aware command system:

1. native plain-text Copy, Cut, and Paste;
2. a visible, sheet-aware Find/Replace panel.

The two features converge because clipboard commands must target either the
active editor selection or the currently focused Find/Replace field without
leaking text across surfaces, panes, or document sheets.

## Ownership boundary

### Luna owns

- the platform-neutral `LunaClipboardService` boundary;
- deterministic in-memory clipboard behavior for tests;
- SDL plain-text clipboard access on Linux;
- application/window identity hints used by SDL hosts;
- reusable UTF-8/grapheme-safe single-line editable field state;
- generic Find/Replace panel layout, hit testing, accessibility, caret, and
  selection rendering;
- visible invalid-regular-expression presentation.

### Moth owns

- Copy, Cut, Paste, Find, navigation, and replacement command IDs;
- command availability and focus routing;
- editor selections and document mutations;
- write-before-delete Cut safety;
- history grouping and Undo/Redo behavior;
- per-document-sheet Find/Replace state;
- search policy, replacement policy, and active-sheet targeting;
- product rendering, status messages, menus, palette entries, and testing.

## Clipboard invariants

- Copy never mutates the document and never creates history.
- Cut writes the clipboard before deleting anything. A failed write leaves the
  document and selection untouched.
- Cut and Paste each create exactly one undoable document operation.
- Paste replaces the active selection or inserts at the active caret.
- Clipboard text is preserved as plain UTF-8 text, including multiple lines,
  tabs, composed/decomposed Unicode, and non-Latin scripts.
- Editor clipboard commands affect only the active pane of the active sheet.
- When the Find panel owns focus, clipboard commands affect only its focused
  field and do not enter document history.

## Find/Replace invariants

- `Ctrl+F` exposes one visible panel projected from the active sheet.
- Query, replacement, options, field caret/selection, and selected result are
  retained independently for every open document sheet.
- Switching tabs saves the previous sheet state and restores the next sheet
  state before results are recalculated against its current revision.
- Find Next/Previous selects the match in the active editor pane and keeps it
  visible.
- Replace Current is one normal history operation.
- Replace All is one atomic history group; one Undo restores the entire prior
  document.
- Invalid regular expressions report a visible error, yield no actionable
  matches, and cannot mutate the document.
- Highlight projection is viewport-bounded so a high-match-count query does not
  make 5K/50K rendering proportional to total result count.

## Commands

| Command | Linux shortcut |
|---|---:|
| Cut | `Ctrl+X` |
| Copy | `Ctrl+C` |
| Paste | `Ctrl+V` |
| Find / Replace | `Ctrl+F` |
| Find Next | `Ctrl+G` or `F3` |
| Find Previous | `Ctrl+Shift+G` or `Shift+F3` |
| Select All | `Ctrl+A` |
| Close Find/Replace | `Escape` |

Inside the panel, `Tab` and `Shift+Tab` move between query and replacement
fields. `Enter` requests Find Next and `Shift+Enter` requests Find Previous.

## Linux application identity

The SDL host receives the product-neutral `applicationID` and `windowClass`
configuration. Moth supplies `io.github.adamjvr.MothText` and `MothTextLinux` so
normal, 5K, and 50K launch paths can match the installed desktop entry and custom
icon instead of falling back to the system-generic application icon.

## Exit condition

M2.2B2 is accepted only after:

- every Luna and Moth automated test passes;
- paired submodule validation passes;
- native external clipboard round trips pass;
- Cut/Paste and Replace All satisfy one-step Undo;
- panel focus routing and per-sheet state pass;
- invalid-regex behavior is visible and non-destructive;
- M3A tabs/panes/dirty-close behavior remains correct;
- ordinary, 5K, and 50K native interaction remains usable;
- every native launch path presents the custom Moth application icon.
