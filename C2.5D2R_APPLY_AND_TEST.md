# Apply and validate Moth C2.5D2R

First commit and push Luna C2.5D2R.

```bash
cd ~/GitHub/Moth-Text
git switch a1.1-measured-audit
git pull --ff-only

LUNA_C25D2R_SHA="$(
  git -C ~/GitHub/Luna-UI rev-parse HEAD
)"

git -C Dependencies/Luna-UI fetch \
  origin \
  a1.1-measured-audit

git -C Dependencies/Luna-UI checkout \
  "$LUNA_C25D2R_SHA"

test \
  "$(git -C Dependencies/Luna-UI rev-parse HEAD)" = \
  "$LUNA_C25D2R_SHA"
```

Apply the Moth repair:

```bash
unzip -o \
  ~/Downloads/Moth-Text-C2.5D2R-Repository-Overlay.zip \
  -d .

git apply --recount --check \
  patches/C2.5D2R_MOTH_RUNTIME_INTEGRATION.patch

git apply --recount \
  patches/C2.5D2R_MOTH_RUNTIME_INTEGRATION.patch
```

Verify actual shell integration:

```bash
./scripts/verify-c2.5d2r-integration.sh
git diff --check
git diff --stat
git diff --submodule=short
```

Focused test:

```bash
swift package reset
swift package resolve

swift test \
  --filter MothC25D2PartialDamageTests
```

Complete validation:

```bash
swift build
swift test
./scripts/test-paired.sh
./scripts/smoke-test-plugin-host.sh
```

Run any additional repository-local validation script you normally use.

Native acceptance:

```bash
swift run MothTextLinux
```

Confirm:

- initial presentation reports `fullScene`;
- ordinary printable typing transitions to `partialDamage`;
- repeated typing keeps both panes synchronized;
- dirty marker, revision, history status, minimap, and caret remain current;
- scrolling reports `partialDamage`;
- menus and command palette use `fullScene`;
- resize rebuilds the backing cache;
- no stale sidebar, title, status, pane, or minimap pixels remain.

Stage the actual shell integration and Luna submodule:

```bash
git add \
  Sources/MothApplication/MothApplicationShellScene.swift \
  scripts/verify-c2.5d2r-integration.sh \
  docs/C2.5D2R_RUNTIME_INTEGRATION_REPAIR.md \
  docs/C2.5D2R_BRANCH_CLOSEOUT.md \
  C2.5D2R_BASELINE.md \
  C2.5D2R_APPLY_AND_TEST.md \
  Dependencies/Luna-UI
```

Required staging guard:

```bash
for required in \
  Sources/MothApplication/MothApplicationShellScene.swift \
  Dependencies/Luna-UI
do
  git diff --cached --name-only | grep -Fxq "$required" || {
    printf 'error: required integration path is not staged: %s\n' "$required" >&2
    exit 1
  }
done
```

Commit and push:

```bash
git diff --cached --check
git diff --cached --submodule=short
git diff --cached --stat

git commit -m \
  "fix(editor): complete C2.5D2 bounded-damage integration"

git push origin a1.1-measured-audit
```

Then follow `docs/C2.5D2R_BRANCH_CLOSEOUT.md`, merging Luna to `main` first.
