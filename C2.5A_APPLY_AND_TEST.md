# Apply and validate Moth C2.5A

Advance Moth to the exact committed Luna C2.5A revision first:

```bash
cd ~/GitHub/Moth-Text
git -C Dependencies/Luna-UI fetch origin
git -C Dependencies/Luna-UI checkout "$LUNA_C25A_SHA"
test "$(git -C Dependencies/Luna-UI rev-parse HEAD)" = "$LUNA_C25A_SHA"
git diff --submodule=short Dependencies/Luna-UI
```

Apply the Moth overlay:

```bash
unzip -o ~/Downloads/Moth-Text-C2.5A-Repository-Overlay.zip -d .
git diff --check
git status --short
```

Focused validation:

```bash
swift test --filter MothC25APresentationStoreTests
```

Full paired validation:

```bash
swift package resolve
swift build
swift test
./scripts/test-paired.sh
./scripts/validate-iteration.sh
./scripts/test-plugin-ipc.sh
git diff --check
```

Commit Moth-owned files and the Luna gitlink together:

```bash
git add \
  Sources/MothApplication/MothDocumentPresentationStore.swift \
  Tests/MothApplicationTests/MothC25APresentationStoreTests.swift \
  docs/C2.5A_SHARED_PRESENTATION_STORE.md \
  C2.5A_APPLY_AND_TEST.md \
  Dependencies/Luna-UI

git diff --cached --check
git diff --cached --stat
git diff --cached --submodule=short
git commit -m "feat(editor): share C2.5A revision presentations"
git push origin a1.1-measured-audit
```
