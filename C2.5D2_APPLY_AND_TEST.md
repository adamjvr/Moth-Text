# Apply and validate Moth C2.5D2

First advance the Luna submodule to the committed Luna C2.5D2 revision:

```bash
cd ~/GitHub/Moth-Text
git switch a1.1-measured-audit
git pull --ff-only

LUNA_C25D2_SHA="$(git -C ~/GitHub/Luna-UI rev-parse HEAD)"

git -C Dependencies/Luna-UI fetch \
  origin \
  a1.1-measured-audit

git -C Dependencies/Luna-UI checkout \
  "$LUNA_C25D2_SHA"

test \
  "$(git -C Dependencies/Luna-UI rev-parse HEAD)" = \
  "$LUNA_C25D2_SHA"
```

Apply:

```bash
unzip -o \
  ~/Downloads/Moth-Text-C2.5D2-Repository-Overlay.zip \
  -d .

git apply --recount --check \
  patches/C2.5D2_MOTH_BOUNDED_DAMAGE.patch

git apply --recount \
  patches/C2.5D2_MOTH_BOUNDED_DAMAGE.patch
```

Validate:

```bash
git diff --check

swift package reset
swift package resolve

swift test \
  --filter MothC25D2PartialDamageTests

swift build
swift test
./scripts/test-paired.sh
./scripts/validate-iteration.sh
./scripts/smoke-test-plugin-host.sh
```

Native check:

```bash
swift run MothTextLinux
```

Validate:

- initial launch reports a complete frame;
- normal text input transitions to `partialDamage`;
- both panes remain correct after repeated input;
- minimap, dirty marker, revision, status, and caret stay synchronized;
- scrolling uses bounded pane/status damage;
- menus, command palette, pointer actions, and resize remain complete frames;
- idle mode remains event-driven.

Review and commit:

```bash
git status --short
git diff --check
git diff --stat
git diff --submodule=short

git add \
  Sources/MothApplication/MothApplicationFrameDamage.swift \
  Sources/MothApplication/MothApplicationShellScene.swift \
  Tests/MothApplicationTests/MothC25D2PartialDamageTests.swift \
  docs/C2.5D2_BOUNDED_EDITOR_DAMAGE.md \
  C2.5D2_BASELINE.md \
  C2.5D2_APPLY_AND_TEST.md \
  Dependencies/Luna-UI

git diff --cached --check
git diff --cached --submodule=short
git diff --cached --stat
git commit -m "perf(editor): adopt C2.5D2 bounded damage"
git push origin a1.1-measured-audit
```
