# C2.5 Sequential Apply and Test Procedure

## 1. Apply Luna reconvene overlay

```bash
cd ~/GitHub/Luna-UI
unzip -o ~/Downloads/Luna-UI-C2.5-Reconvene-Repository-Overlay.zip -d .
git status --short
git diff --check
```

Review `docs/C2.5_PAIRED_SCALABILITY_RECONVENE.md`.

## 2. Implement, test, commit, and push Luna

The future implementation overlay is applied to Luna first. Run focused tests, the
full Luna suite, native graphical validation, then commit and push. Record:

```bash
LUNA_C25_SHA="$(git -C ~/GitHub/Luna-UI rev-parse HEAD)"
```

Wait for Luna CI before changing Moth's submodule.

## 3. Pull committed Luna into Moth

```bash
cd ~/GitHub/Moth-Text
git -C Dependencies/Luna-UI fetch origin
git -C Dependencies/Luna-UI checkout "$LUNA_C25_SHA"
test "$(git -C Dependencies/Luna-UI rev-parse HEAD)" = "$LUNA_C25_SHA"
git diff --submodule=short Dependencies/Luna-UI
```

Do not reset the submodule after this step.

## 4. Apply Moth reconvene overlay

```bash
cd ~/GitHub/Moth-Text
unzip -o ~/Downloads/Moth-Text-C2.5-Reconvene-Repository-Overlay.zip -d .
git status --short
git diff --check
git diff --submodule=short Dependencies/Luna-UI
```

Review `docs/C2.5_PAIRED_SCALABILITY_RECONVENE.md`.

## 5. Implement and test Moth against committed Luna

Run the focused Moth C2.5 tests, full paired suite, native Moth validation, the
resumable audit smoke scenarios, and plugin IPC smoke test. Commit Moth-owned files
and `Dependencies/Luna-UI` together only after acceptance.
