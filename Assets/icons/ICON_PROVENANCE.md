# Moth Text Icon Processing

The source was Adam's 1254×1254 Moth Text mockup.

Processing was intentionally limited to application-icon formatting:

- the RGB values of every source pixel were preserved exactly in the full-resolution
  cleaned master;
- only the alpha channel was changed for the connected white exterior and its
  anti-aliased boundary;
- the internal dark blue/purple gradient and neon moth/skull artwork were not
  redesigned or recolored;
- standard Linux hicolor sizes were generated from the cleaned master.
